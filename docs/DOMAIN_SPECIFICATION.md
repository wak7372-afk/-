# مواصفات نطاق مركز ذات خيل لتعليم القرآن الكريم وعلومه

الحالة: مسودة اعتماد المرحلة صفر
آخر تحديث: 2026-08-09
المرجع الحاكم: هذه الوثيقة ثم قرارات المستخدم اللاحقة الموثقة فيها.

## 1. المصطلحات

- **الحلقة**: مساحة تعليمية لها أعضاء وفريق تعليم ومحتوى وساحة وإعدادات.
- **الحلقة القرآنية**: حلقة تعتمد تقارير يومية مستوردة من Excel، ولا تستخدم منشئ المهام التعليمية.
- **الحلقة التعليمية**: حلقة لمادة واحدة أو عدة مواد، وتستخدم مهام ينشئها المعلم يدويا.
- **التقرير القرآني**: مقرر لطالب في يوم وفترة محددين، وتصنيفه حفظ أو مراجعة أو تثبيت دون اختلاف في محرك الإنجاز.
- **المهمة التعليمية**: نشاط يدوي بلا درجات، وقد يتطلب إرسال إجابات أو صحتها أو اعتماد المعلم.
- **المعلم المسؤول**: معلم واحد يدير الحلقة ويملك الصلاحيات الحساسة.
- **المعلم المساعد**: معلم مرتبط بالحلقة، ويحصل على صلاحيات إضافية بتفويض صريح من المسؤول.
- **الإنجاز في الوقت**: اكتمال التقرير أو المهمة قبل الموعد الأصلي أو داخل تمديد معتمد.
- **التأخير**: اكتمال العمل بعد الموعد الفعال، مع حفظ وقت الإكمال الفعلي.
- **الإعفاء**: قرار معلم يقفل التقرير كمعذور ويفك الحجب دون مطالبة الطالب بإكماله.

## 2. قواعد العضوية

1. الطالب لا يملك أكثر من عضوية نشطة في حلقة قرآنية واحدة.
2. الطالب يستطيع الانضمام إلى عدة حلقات تعليمية.
3. الحلقة التعليمية قد ترتبط بعدة مواد.
4. المدير وحده ينشئ الحلقات ويحدد المعلم المسؤول والمعلمين المساعدين.
5. إضافة طالب مرتبط بحلقة قرآنية أخرى تنشئ طلب نقل للمدير ولا تنقله مباشرة.
6. يعرض طلب النقل الحلقة الحالية وفريقها وآخر التقارير وموضع الحفظ والسجل الضروري للقرار.
7. لا تحذف العضويات السابقة؛ تؤرشف بتاريخ البداية والنهاية وسبب الإنهاء.

## 3. مصفوفة الصلاحيات

| العملية | المدير | المسؤول | المساعد | الطالب |
|---|---:|---:|---:|---:|
| إنشاء الحلقة وأرشفتها | نعم | لا | لا | لا |
| تعيين الفريق والطلاب والمواد | نعم | لا | لا | لا |
| ضبط صلاحيات المساعد | مراقبة وتدخل | نعم | لا | لا |
| رفع تقارير القرآن واعتمادها | مراقبة وتدخل | نعم | لا | لا |
| تعديل تقارير القرآن | مراقبة وتدخل | نعم | لا | لا |
| إنشاء مهمة تعليمية | مراقبة وتدخل | نعم | بتفويض | لا |
| مراجعة تسليم تعليمي | مراقبة | نعم | بتفويض | لا |
| اعتماد تمديد أو عذر | مراقبة وتدخل | نعم | لا | طلب فقط |
| متابعة الطلاب والتقييم | نعم | نعم | نعم | سجله فقط |

كل صلاحية تفرض في قاعدة البيانات أو دالة خادمية، ولا يكفي إخفاء زر الواجهة.

## 4. تقارير الحلقات القرآنية

1. ملف Excel الواحد يخص حلقة واحدة ويحتوي تقارير طلابها.
2. يقرأ النظام الطالب والتاريخ واليوم والفترة والنوع والمحتوى وبيانات الوقت.
3. يسبق الحفظ عرض معاينة يبين الصفوف الصحيحة والأخطاء والتكرارات والطلاب غير المطابقين.
4. الاعتماد عملية ذرية: يحفظ الملف كله أو لا يحفظ منه شيء.
5. يستطيع المسؤول تعديل التقرير بعد النشر، مع إصدار سابق وسجل للمعدل ووقت التعديل وإشعار الطالب.
6. صفحة **تقاريري** تجمع تقارير الطالب من كل حلقاته، وصفحة الحلقة تعرض تقارير تلك الحلقة فقط.
7. لا يستطيع الطالب إنهاء التقرير قبل وقت بدايته، ويستطيع إنهاءه بعد الموعد مع تسجيل التأخير.
8. أي تقرير سابق متأخر وغير منجز يحجب التقارير اللاحقة حتى الإنجاز أو الإعفاء؛ التمديد النشط لا يلغي الحجب.

## 5. الفترات والقوائم

- الموعد الأصلي للصباح: 18:00، وإقفال قائمته النهائية: 23:00.
- الموعد الأصلي للمساء: 23:00، وإقفال قائمته النهائية: 06:00 من اليوم التالي.
- قبل الموعد: منجز في الوقت. بين الموعد والإقفال: منجز متأخرا. بعد الإقفال دون إنجاز: غير منجز.
- القوائم العامة تعرض المنجزين في الوقت والمتأخرين وغير المنجزين وأصحاب التمديد النشط.
- الإنجاز أثناء تمديد معتمد يصنف منجزا في الوقت.
- تصنيف سرعة الإنجاز يقسم الوقت المتاح إلى ثلاثة أثلاث: أخضر، برتقالي، أحمر؛ وبعد الموعد يظهر أحمر بعبارة متأخر.
- المعذورون فئة مستقلة ولا يدخلون في نسبة الالتزام.

## 6. التمديدات والأعذار

1. الطالب يطلب مدة تمديد وسببا لمهمة واحدة أو عدة مهام، ولا يحدد وقت النهاية.
2. المسؤول يقبل أو يرفض كل تقرير على حدة، ويستطيع تحديد مدة أو تاريخ ووقت نهاية.
3. إذا اعتمد الطلب قبل الموعد الأصلي تبدأ المدة بعد الموعد الأصلي؛ وإذا اعتمد بعده تبدأ من وقت الاعتماد.
4. يسمح بطلب جديد بعد رفض التمديد، مع طلب معلق واحد فقط لكل تقرير.
5. العذر متاح لتقرير متأخر غير منجز بلا تمديد نشط خلال 72 ساعة من الموعد، ولا يتطلب مرفقا.
6. قبول العذر يعفي التقرير ويفك الحجب، ورفضه يبقي التأخير والحجب ولا يسمح بإعادة طلب العذر نفسه.

## 7. مهام الحلقات التعليمية

1. تنشأ يدويا ولا تستورد من Excel ولا تستخدم درجات.
2. يدعم المنشئ: اختيار واحد، اختيار متعدد، صح أو خطأ، إجابة قصيرة، مقالية، رفع ملف، مطابقة وترتيب.
3. تحتوي المهمة عنوانا وتعليمات ومادة ومرفقات ومستهدفين ووقت نشر وبداية ونهاية وعدد محاولات.
4. يختار المعلم شرط الإتمام: الإرسال فقط، صحة الإجابات الموضوعية، اعتماد المعلم، أو وضع مختلط.
5. الحالات: مسودة، مجدولة، متاحة، قيد الحل، بانتظار المراجعة، مكتملة في الوقت، مكتملة متأخرة، غير مكتملة، معفاة.
6. يستطيع المسؤول تفويض مساعد بإنشاء المهام أو مراجعتها لكل حلقة على حدة.

## 8. ساحة الحلقة

- التبويبات الأساسية: الساحة، التقارير أو المهام، الأشخاص، الملفات، الأداء، الإعدادات.
- المنشورات: إعلان، لقاء مباشر، ملف، موضوع نقاش، ورسالة نظام آلية.
- حلقة القرآن: المعلمون والنظام ينشرون والطلاب يقرؤون.
- الحلقة التعليمية: يستطيع الطالب إنشاء موضوع جديد أو الرد على موضوع قائم، مع احتفاظ المعلم بصلاحية إغلاق النقاش أو حذف المحتوى المخالف.
- تحتوي إعدادات الحلقة على حقل واضح يلصق فيه المعلم رابط Google Meet، ثم يظهر زر دخول للطلاب الأعضاء.
- لا يطلب النظام بيانات حساب Google، ويفتح الرابط الخارجي المعتمد فقط.
- لا يرى الرابط أو المحتوى إلا عضو نشط في الحلقة أو مدير مخول.

## 9. المحاسبة والتواصل

- تعرض شاشة المحاسبة حالة كل طالب للفترتين والوقت المتبقي وعدد التقارير المتأخرة.
- فتح الطالب يعرض سجله الكامل وفلاتر الحالة والفترة والنوع، مع تصدير Excel وPDF.
- الطالب يراسل معلما واحدا مرتبطا به في حلقة نشطة، ولا توجد محادثات طالب مع طالب.
- دليل بدء المحادثة يبين اسم المعلم ودوره والحلقات والمواد المشتركة.
- يدعم الإصدار الأول نصوصا وصورا وملفات PDF وWord ورسائل صوتية ضمن حدود حجم ونوع آمنة.
- عند انتهاء آخر علاقة تعليمية مشتركة تبقى المحادثة للقراءة فقط وتمنع الرسائل الجديدة.
- الساحة العامة تتبع قواعد نوع الحلقة وإعدادات النشر.

## 10. متطلبات الإنتاج

- وقت الخادم هو المرجع لكل الحالات الزمنية.
- كل عملية حساسة تسجل في سجل تدقيق غير قابل لتعديل المستخدم.
- الوظائف المجدولة قابلة لإعادة المحاولة دون إنشاء قائمة أو إشعار مكرر.
- عمليات الاستيراد والتعديل تحتفظ بالمصدر والإصدار وهوية المنفذ.
- يلزم اختبار RLS لكل دور، ونسخ احتياطي مجرب، وخطة رجوع قبل النشر.

## 11. صلاحيات المساعد المعتمدة

يمنح المعلم المسؤول صلاحيات المساعد بصورة مستقلة داخل كل حلقة، وتشمل: نشر إعلان، تعديل رابط اللقاء، إنشاء مهمة تعليمية، مراجعة التسليم، متابعة الطلاب، وإدارة النقاش. سحب صلاحية لا يلغي السجلات السابقة ولا ينسب أعمال المساعد إلى المسؤول.
