# نظام تصميم مركز ذات خيل - الإصدار الأول

## الهدف

يوحد هذا النظام هوية واجهات المدير والمعلم والطالب والحلقات، ويجعل القراءة والعمل اليومي أسرع من دون تغيير منطق البيانات أو الصلاحيات.

## المبدأ البصري

الفخامة الهادئة: واجهة رصينة، واضحة، قليلة الضجيج، تستمد هويتها من الألوان والنسب والخط العربي أكثر من كثرة الزخارف.

## الألوان

| الاستخدام | الرمز |
| --- | --- |
| الحبر والعناوين | `#071827` |
| الكحلي القيادي | `#071A2B` |
| الأخضر والإنجاز | `#0B6A4D` |
| الأزرق والمعلومات | `#1D638C` |
| الذهبي والهوية | `#D4AD43` |
| الأحمر والتنبيه | `#B44348` |
| خلفية التطبيق | `#F5F7F8` |
| حدود العناصر | `#D8E1E5` |

لا يستخدم الأحمر للزينة أو لانخفاض النقاط وحده. يخصص للحالات التي تحتاج إجراء واضحاً.

## الخطوط

- `Cairo` أو `Noto Kufi Arabic` للنصوص والبيانات والأزرار.
- `Amiri` للعناوين القرآنية وعناوين الصفحات البارزة.
- الحد الأدنى العملي للنص الثانوي هو `12px`، والنص الأساسي بين `14px` و`16px`.
- يجب أن يبقى المحتوى صالحاً عند تكبير النص إلى `200%`.

## المسافات والأسطح

- نصف قطر البطاقات والألواح `8px` كحد أقصى.
- تستخدم البطاقات للعناصر المتكررة فقط، ولا توضع بطاقة داخل بطاقة.
- الظلال خفيفة وتوضح الارتفاع الوظيفي، ولا تستخدم كزخرفة.
- النقوش الإسلامية محصورة في رؤوس الصفحات والأشرطة القيادية وبشفافية منخفضة.

## الأوامر والحالات

- لكل شاشة أمر رئيسي واحد واضح.
- الحد الأدنى للأزرار وحقول الإدخال المهمة `44px`.
- كل حالة تعرض لوناً ورمزاً وعبارة؛ اللون وحده غير كاف.
- الحالات الموحدة: محايد أزرق، مكتمل أخضر، يقترب موعده ذهبي، متأخر أحمر، معفى رمادي.
- رسائل الخطأ تكتب بالعربية وتظهر بجوار مكان المشكلة.

## هيكل الأدوار

- الطالب: اليوم، التقارير، الحلقات، الرسائل، حسابي.
- المعلم: مركز المتابعة، الحلقات، التقارير، الطلاب، الرسائل.
- المدير: الرئيسية، الحسابات والصلاحيات، إدارة الحلقات، الرقابة، إعدادات النظام.
- الهاتف يستخدم شريطاً سفلياً ثابتاً، وتبقى الإجراءات الثانوية في رأس الصفحة.

## الحركة والوصول

- الحركة قصيرة ومرتبطة بنتيجة فعل المستخدم.
- يحترم النظام إعداد `prefers-reduced-motion`.
- لكل عنصر تفاعلي حالة تركيز مرئية بلوحة المفاتيح.
- يجب فحص كل صفحة على عرضي `1280px` و`390px` قبل اعتمادها.

## التطبيق

طبقة التنفيذ المشتركة موجودة في `public/css/design-system.css`. تضاف بعد ملف CSS الخاص بالصفحة حتى تكون المرجع النهائي للهوية وقواعد الوصول.
